# ChilloCafé

موقع مقهى عربي (RTL) مع لوحة إدارة تجريبية تعمل في المتصفح فقط، مبني بـ React وTypeScript وVite.

## التشغيل

```bash
npm install
npm run dev           # خادم التطوير
npm run build         # فحص TypeScript وبناء الإنتاج في dist/
npm run preview       # معاينة نسخة الإنتاج
npm run lint          # ESLint
npm run check:assets  # التحقق من الكتالوج ومن وجود كل الأصول المحلية
```

عند النشر على استضافة ثابتة، يجب توجيه كل المسارات إلى `index.html` حتى تعمل روابط مثل `/products` عند فتحها مباشرة.

## ما الذي يمكن تعديله؟

| الملف | المحتوى |
| --- | --- |
| `src/config/site.ts` | بيانات التواصل والعنوان وساعات العمل والروابط الاجتماعية ونصوص التذييل. كل القيم الحالية **تجريبية** |
| `src/data/products.ts` | كتالوج المنتجات الأساسية |
| `src/data/categories.ts` | أسماء التصنيفات |
| `src/styles/tokens.css` | الألوان والمسافات والظلال والحركة |

## المنتجات المؤقتة

تعيش المنتجات المضافة من لوحة الإدارة في حالة React داخل `src/context/ProductsContext.tsx` فقط، ولا تُستخدم أي وسيلة تخزين دائمة. تبقى عند التنقل داخل الموقع، وتختفي عند تحديث الصفحة. والصور المرفوعة تُقرأ كـ data URL في الذاكرة. لوحة الإدارة مفتوحة للجميع وليست محمية.

## الصور

الصور في `public/assets/` مأخوذة من Wikimedia Commons بتراخيص حرة، وبعضها يشترط نسبة العمل إلى صاحبه أو المشاركة بالمثل. التفاصيل الكاملة في `src/data/imageCredits.ts`، وتعرضها صفحة `/credits` المرتبطة من التذييل؛ أبقِها منشورة ما دامت هذه الصور مستخدمة.

الشعار ملف SVG محلي (`public/assets/branding/`) محوّل نصه إلى مسارات من خط Playfair Display (ترخيص OFL)، فلا يحتاج إلى أي خط عند العرض.
